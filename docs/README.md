# Documentation

- `ssot.md` — product and business single source of truth (problem, scope, definitions, decision log)
- `implementation_plan.md` — how the SSOT is realized (architecture, workstreams, phases); not a task list
- `work_plan.md` — execution plan (tasks, sequence, definition of done)
- `proposal.md` — career / portfolio intent (why this project exists); not the product SSOT
- `architecture/` — system diagram (user, agent, tools, DB, retrieval, analytics, validation, output)
- `evaluation/` — benchmark design, metrics, baseline, results, error analysis, limitations
- `writeup/` — ~1,500–2,000 word technical write-up
